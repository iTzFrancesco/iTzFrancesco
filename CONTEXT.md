# GitHub Profile README

This context defines the language used by the profile README: a compact, technical introduction that helps developers, AI engineers, and community members understand what Francesco builds and how to work with him.

## Profile language

**Featured project**:
A project selected to prove a specific engineering capability. The profile contains DJI RC-N1C Flight Deck, Traflix Voice, Traflix Space, and GigaMC, in that order.
_Avoid_: Project dump, side-project list

**Technical proof**:
A concise description of what was built, how it works, and why it is useful to people who use it.
_Avoid_: Keyword salad, vague claims

**Practical AI**:
AI integrated into a concrete user workflow with an explicit trade-off, such as Traflix Voice's local privacy versus optional cloud speed and Traflix Space's workspace-scoped agent context.
_Avoid_: AI as a generic label

**AI workflow**:
A concise description of the loop: capture intent, keep project context together, run focused agent passes, and verify the change before shipping.
_Avoid_: Presenting AI as an autonomous replacement for engineering judgment

**Project prose**:
Lead with what the product enables and what makes it special, explain the practical outcome, and finish with one short `Stack:` sentence. Keep metrics tied to their measured path.
_Avoid_: Keyword salad, unsupported claims, technology inventory

**Collaboration**:
An explicit invitation to work on open-source projects, developer tools, and useful software.
_Avoid_: Generic networking language
